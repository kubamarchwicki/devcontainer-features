# Plannotator (`plannotator`)

Installs the [Plannotator](https://plannotator.ai/) binary during the image build, so it is cached in the image layer instead of being installed in `onCreateCommand`. It runs the official installer with `--minimal` (binary only, no per-agent integrations) and places the binary in `/usr/local/lib/plannotator`, with a wrapper at `/usr/local/bin/plannotator`.

```json
{
    "features": {
        "ghcr.io/kubamarchwicki/devcontainer-features/plannotator:1": {
            "port": "${localEnv:DC_PLANNOTATOR_PORT:19432}",
            "urlHost": "${localEnv:DC_PLANNOTATOR_HOST:localhost}"
        }
    }
}
```

## Options

| Option | Environment variable | Default | Description |
| --- | --- | --- | --- |
| `version` | | `latest` | Release tag, such as `v0.17.2`, or `latest`. |
| `remote` | `PLANNOTATOR_REMOTE` | `1` | Default for the variable. |
| `agentTerminalRemote` | `PLANNOTATOR_AGENT_TERMINAL_REMOTE` | `1` | Default for the variable. |
| `port` | `PLANNOTATOR_PORT` | `19432` | Default for the variable. |
| `urlHost` | `PLANNOTATOR_URL_HOST` | `localhost` | Default for the variable. |

An empty option leaves the variable unset. The wrapper applies these values as defaults only, so a variable already set in the container environment (for example through `containerEnv`) takes precedence. Option values may contain only letters, digits, and `._:/@-`.

## Testing

```sh
devcontainer features test --project-folder . --features plannotator --skip-autogenerated
```
